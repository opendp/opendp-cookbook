# The OpenDP Cookbook

The OpenDP Cookbook is a collection of recipes for the
[OpenDP Library](https://docs.opendp.org/),
contributed by the user community.

This is lightly curated: We check that the recipes run
with the latest version of OpenDP,
but there are many different ways to cook with OpenDP,
and there may be other approaches which provide better results for particular applications.

If you want to learn more about differential privacy beyond the OpenDP Library,
our [educational resources](https://learning.opendp.org/) are a good place to begin.
